# 인공지능응용 수업시간에 진행한 내용정리

인공지능응용 수업의 실습 코드와 배운 내용을 주차별로 정리한 저장소입니다.

## 3주차 실습: 합성 트랙으로 End-to-End 자율주행 체험

실습 노트북: [Week03_demo.ipynb](week03/Week03_demo.ipynb)

시뮬레이터 없이 도로 이미지를 직접 만들어, **카메라 이미지에서 조향값을 예측하는 모델**을 학습했습니다. 데이터를 만들고, 모델을 학습·평가하고, 모델의 조향으로 차량을 움직이는 폐루프 주행까지 한 노트북에서 진행합니다.

### 실습 흐름

1. **도로 이미지와 정답 생성:** 차량의 측면 위치 `d`, 도로 방향과의 각도 차이 `psi`, 도로 곡률 `kappa`로 66×200 이미지를 그립니다. 미리 정한 `expert_steer()` 규칙이 각 이미지의 정답 조향값을 만듭니다.
2. **데이터 확인과 분할:** 이미지·조향값 5,000쌍을 만들고 조향 분포를 확인합니다. 같은 주행에서 나온 프레임이 학습과 검증에 동시에 들어가지 않도록 주행 10개 중 8개를 학습, 2개를 검증에 사용합니다.
3. **모델 학습:** `TinyPilotNet`이 이미지를 입력받아 조향값 하나를 출력합니다. MSE 손실과 Adam 옵티마이저로 학습하고, 검증 손실이 가장 낮은 가중치를 저장합니다.
4. **오프라인 평가와 변환:** 검증 데이터의 MAE, 정답·예측 비교, 오차가 큰 이미지를 살펴봅니다. 모델을 ONNX 형식으로 변환하고 CPU 추론 시간을 측정합니다.
5. **폐루프 평가:** 모델의 조향이 다음 차량 위치와 다음 카메라 이미지에 반영되도록 주행시킵니다. 주기적인 외란을 가한 뒤 전문가 규칙과 모델의 도로 이탈 횟수를 비교합니다.
6. **데이터 분포 실험:** `STATE_SPREAD`를 `0.05`, `0.15`, `0.30`으로 바꿔 새 모델을 각각 학습하고, 폐루프 이탈 횟수가 어떻게 달라지는지 확인합니다.

### 수업에서 확인한 점

- `expert_steer()`는 차량 상태를 아는 **수동으로 정한 규칙**입니다. 이미지 모델은 이 규칙이 만든 조향값을 정답으로 학습합니다.
- `STATE_SPREAD`는 학습용 상태의 퍼짐을 정합니다. 값이 클수록 도로 중앙에서 벗어나거나 방향이 틀어진 장면이 학습 데이터에 더 많이 포함됩니다.
- 검증 이미지에서 조향 오차가 작아도, 모델이 직접 운전할 때는 실수가 다음 상태에 누적되어 이탈할 수 있습니다. 따라서 오프라인 오차와 폐루프 주행 결과를 함께 봐야 합니다.
