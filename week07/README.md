# 7주차 — DAgger 주행 정책 제출

제출 모델: [my_policy_v2.onnx](my_policy_v2.onnx)

기존 정책 v1과 DAgger D1~D10을 같은 시드 5개(`0, 1, 2, 3, 4`)로 비교했습니다.
공개 트랙 A·B·C와 미공개 트랙(random seed 101·202)에서 외란 1.0×·1.2×를 각각 평가하고,
네 조건의 평균 점수가 가장 높은 **D8**를 선택했습니다.
총 11개 모델 × 4개 조건 × 5개 시드 = 220회 평가이며, 실제 제출하는 ONNX 모델로 측정했습니다.
평균은 네 조건에 같은 가중치를 부여합니다. 수치는 해당 평가 표본의 결과입니다.

| 평가 조건 | 시드 5개 평균 점수 |
|---|---:|
| 공개 · 외란 1.0× | 88.93 |
| 공개 · 외란 1.2× | 86.28 |
| 미공개 · 외란 1.0× | 88.89 |
| 미공개 · 외란 1.2× | 86.25 |
| **전체 평균** | **87.59** |

## 모델 계약

- 입력: `image`, float32, `(N, 3, 66, 200)`. 배치 크기 N은 가변이며 주행 평가에서는 1입니다.
- 전처리: RGB 이미지를 255로 나누어 0~1로 정규화하고 NCHW로 변환합니다.
- 출력: `steer`, float32, `(N, 1)` 조향값.
- 원본 체크포인트: `policy_round8.pt`. ONNX opset 17.
- `tinytrack` 0.3.1, 외란 주기 50스텝, 평가 노이즈 0.02, 속도 배율 1.0.

## 검증 및 기록

ONNX 구조 검사를 통과했고, 합성 이미지 64장에서 원본 PyTorch 모델과의 최대 예측 차이는
`3.58e-07`였습니다. 공개 트랙·강한 외란·시드 0의 폐루프 점수도 원본 모델과 0.01점 이내로 일치했습니다.
