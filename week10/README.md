## 문제 5 — BC→PPO 미세조정

8개 환경 × 64스텝으로 경험을 수집했습니다. 제공 코드가 반복 수를 정수 나눗셈으로
계산하므로 `TOTAL=8000`에서 실제 학습량은 15회 × 512 = **7,680스텝**입니다.
워밍업 3회, Actor 학습률 1e-4, Critic 학습률 3e-4, `bc_coef=0.3`을 사용했습니다.
트랙 B의 외란 1.2배 점수는 시작 **86.948 → 최고 87.1**이었습니다.
최고 정책은 시작 정책도 후보에 포함하여 선택했습니다.

## 심화 — BC 정규화 계수 비교

공개 A/B/C, 시드 0에서 동일한 설정으로 각 계수를 평가했습니다.
제공 코드의 `4000 // 512`에 따라 실제 학습량은 각 **3,584스텝**입니다.

| bc_coef | 기본 score | 외란 1.2배 score |
|---|---:|---:|
| 시작 정책 | 89.5 | 87.1 |
| 0.0 | 89.2 | 9.6 |
| 0.3 | 89.3 | 9.6 |
| 1.0 | 89.1 | 19.1 |

1. `bc_coef=0`에서는 기본 성능은 거의 유지했지만 외란 복구 성능이 크게 저하되었습니다.
2. `0.3`에서도 충분한 성능 보호가 관찰되지 않았습니다. `1.0`은 외란 점수 저하가 상대적으로 작았지만 시작 정책보다 낮았습니다.
3. 동일 시드의 짧은 학습 결과만으로 특정 계수가 최적이거나 학습을 막는다고 단정할 수 없으며, 더 긴 학습과 여러 시드에서 확인할 필요가 있습니다.

문제 4의 L2는 외란 주기 40스텝이고, 미세조정·심화의 HARD는 50스텝이므로 조건이 다릅니다.
또한 심화는 마지막 정책을 평가하고, 문제 5는 학습 중의 최고 정책을 보존합니다.
